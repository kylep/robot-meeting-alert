# Hardware inventory

## Freenove Basic Starter Kit for Raspberry Pi Pico (FNK0064)

- Variant: Raspberry Pi Pico 2 W (RP2350, dual Arm Cortex-M33 / Hazard3
  RISC-V, 150 MHz, 520 KB SRAM, Wi-Fi + Bluetooth)
- Purchased from: Amazon.ca, ASIN [B0DRJV9JJW](https://www.amazon.ca/dp/B0DRJV9JJW)
- Official repo (tutorials, code, datasheets, parts list):
  <https://github.com/Freenove/Freenove_Basic_Starter_Kit_for_Raspberry_Pi_Pico>
  - MicroPython tutorial: `Python/Python_Tutorial.pdf`
  - C tutorial: `C/C_Tutorial.pdf`
  - Parts list image: `Picture/PartsList.jpg` (it shows the original Pico,
    but the contents are otherwise the same)

### Not included

There is no display, servo, motor, motor driver or relay. The repo's
`Datasheet/` folder has LCD1602, MPU-6050 and L293D datasheets, but those
parts come with other Freenove Pico kits, not this one.
